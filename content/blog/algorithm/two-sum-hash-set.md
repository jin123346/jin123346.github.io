## 문제 요약

- **문제:** 개인 연습 문제 (별도 공식 원문 링크 없음)
- **플랫폼 / 난이도:** 개인 연습 · Two Sum 존재 여부 변형
- **입력 크기:** 정수 배열 N개, 목표값 1개. 원소 쌍이 존재하는지만 확인한다.

서로 다른 두 원소의 합이 target이 되는 쌍이 있다면 True를 반환한다. LeetCode Two Sum 원문처럼 인덱스를 반환하는 문제는 아닌 변형이다.

## 접근 방법

처음에는 모든 두 수를 비교하는 O(N²) 방법을 떠올렸다. 현재 수 `num`에 필요한 다른 값 `target - num`을 이미 방문했는지 확인하면 한 번 순회할 수 있다. **검사 후 저장**해야 같은 요소를 두 번 쓰지 않는다.

## 풀이 코드

```python
def solution(nums, target):
    seen = set()
    for num in nums:
        need = target - num
        if need in seen:
            return True
        seen.add(num)
    return False
```

## 복잡도

| 구분 | 복잡도 | 근거 |
| --- | --- | --- |
| 시간 | O(N) 평균 | N개 수를 한 번 순회하며 집합 포함 여부를 평균 O(1)에 확인한다. |
| 공간 | O(N) | 최악의 경우 N개 값을 집합에 저장한다. |

## 막혔던 부분

`seen.add(num)`을 검사보다 먼저 수행하면 target이 2*num인 경우 자기 자신을 재사용한 것으로 오인할 수 있다.

## 다른 풀이와 비교

이중 반복문은 O(N²)이지만 직관적이다. 해시 집합은 평균 O(N)으로 개선된다.
