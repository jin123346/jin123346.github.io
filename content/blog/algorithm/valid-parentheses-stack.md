## 문제 요약

- **문제:** [올바른 괄호](https://school.programmers.co.kr/learn/courses/30/lessons/12909)
- **플랫폼 / 난이도:** 프로그래머스 Lv.2
- **입력 크기:** 괄호로 구성된 문자열 길이 N.

문자열의 괄호가 순서대로 올바르게 짝지어지는지 확인한다.

## 접근 방법

여는 괄호를 만나면 카운터를 늘리고 닫는 괄호를 만나면 줄인다. 중간에 음수가 되면 짝지을 여는 괄호가 없으므로 즉시 실패한다.

## 풀이 코드

```python
def solution(s):
    balance = 0
    for ch in s:
        if ch == '(':
            balance += 1
        else:
            balance -= 1
            if balance < 0:
                return False
    return balance == 0
```

## 복잡도

| 구분 | 복잡도 | 근거 |
| --- | --- | --- |
| 시간 | O(N) | 각 문자를 한 번 확인한다. |
| 공간 | O(1) | 카운터 정수 하나만 보관한다. |

## 막혔던 부분

마지막 균형이 0이어도 `)(`처럼 중간에 닫는 괄호가 먼저 나오는 문자열은 올바르지 않다.

## 다른 풀이와 비교

스택 `append`/`pop`도 O(N) 시간으로 가능하며 O(N) 공간을 사용한다. 괄호 종류가 하나라면 카운터가 더 단순하다.

## 정리

- **이 유형을 알아보는 단서:** 중간 불변식(음수가 되면 안 됨) 확인하기
- **다음에 기억할 점:** 스택과 카운터 중 필요한 표현 선택하기
